# Extremely projective normed spaces

- `paper_eng/`: the paper (English).
- `talk/`: an 80-minute Beamer talk on the paper, with speaker notes.
- `preliminaries/`: a crash course on the set theory used in sections 6 and 7
  of the paper.

Each directory has its own README with build instructions; compiled PDFs are
kept in the `out/` subdirectories.
